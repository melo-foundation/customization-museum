Messenger Skins

Give Messenger a fresh new look

Important: You need to have Messenger Plus! Live installed before being able to install Skins.

What are Skins?

Skins change the way your Messenger windows look. We have some awesome designs available for download which will greatly improve the old Live Messenger look. Messenger Plus! Skins are very easy to install, just browse the database, download a skin you like and open the file: Messenger Plus! will take care of the rest. Going back to the default look is not a problem either in case you'd change your mind. Enjoy!

These are nice and all... but how can I create mine?!

To create your own skin, all you need to know can be found in the resources for skin creators section. Some basic understanding of XML is required but anybody with some motivation can learn how to work with the system. Messenger Plus! skins don't patch Messenger, they load the resources into memory, making your skins easy for people to use and survive Messenger updates. Questions about skinning can be posted in the skinning section of the forum.
